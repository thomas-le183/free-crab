# free-crab

A sandbox repository for practicing version control workflows — branching, merging,
rebasing, conflict resolution, tags, and PRs.

## Setup

```bash
npm install
```

## Scripts

| Command             | Purpose                        |
| ------------------- | ------------------------------ |
| `npm run build`     | Compile TypeScript to `dist/`  |
| `npm test`          | Run the test suite once        |
| `npm run test:watch`| Run tests in watch mode        |
| `npm run typecheck` | Type-check without emitting    |

## Layout

```
src/    library source
test/   vitest specs
```
